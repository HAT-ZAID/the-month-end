## Context

Running `run_pipeline` locally produces a materially different frame from the
committed `output.csv` — vision/OCR backend differences. This predates the
remediation branch and is why byte identity is verified by not touching the file
rather than by regenerating it.

## Proposal

Pin the OCR/vision backend and its version, or record that `output.csv` is
generated only in the reference environment.

## Acceptance

A clean run reproduces the committed hash, or the requirement is documented
explicitly.
