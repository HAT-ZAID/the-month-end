## Reply

```
1. `D = (full - mtd)`
Reasoning: In 19/21 cases, the total drop equals the remaining budget for the current month; the reference ignores future months and only subtracts the current month's remaining spend.

2. `D = max(full - mtd, (full - mtd) * (to_deadline / 30))`
Reasoning: For rows 05 and 10, D is significantly higher than (full-mtd), suggesting a multiplier based on the time horizon (to_deadline) when certain conditions are met.

3. `safe = bal - floor - (full - mtd)`
Reasoning: The reference calculates the "safe" amount by subtracting only the current month's remaining budget from the available liquidity (bal - floor), rather than projecting over 90 days.
```
